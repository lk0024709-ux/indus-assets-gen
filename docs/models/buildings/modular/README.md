## Recipe format
Recipes live at the bottom of `tools/assemble_buildings.py`:

```python
dict(name="house_small", nx=2, ny=2, floors=1, roof="slanted",
     wall="Sandstone", trim="WoodDark", floor="ConcreteGrey", roof_mat="BrickRed",
     walls={"S": ["door", "window"], "N": ["window", "solid"],
            "E": ["window", "solid"], "W": ["solid", "solid"]})
```

`walls` lists one entry per 10 m bay, starting from the **west/left** end of each
side. Valid bay values: `solid`, `window`, `door`, `garage`. Doors only appear on
the ground floor — upper storeys convert them to windows automatically.
`roof` is `flat`, `slanted` or `none`; `destroy=<0..1>` randomly deletes that
fraction of faces after joining (used by `ruined_building`).
