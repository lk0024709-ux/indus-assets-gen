Generated by `tools/generate_building_modules.py` (bpy, solid palette colours, flat shading).
Every module's origin is **bottom-centre (0, 0, 0)** — drop it at `(0,0,0)` and it sits on the ground.

## Grid convention used by the assembler

* module footprint **15 × 15 m**, storey height **3.0 m**, slab **0.2 m**, wall **0.2 m**
* footprint of an `nx × ny` building = `nx*15 × ny*15` metres (1×1 = 15×15, 2×1 = 30×15, 2×2 = 30×30, 3×2 = 45×30)
* side walls sit on the cell line (`y = ∓D/2`, `x = ∓W/2`), plinth band protrudes 0.06 m
* floor slabs at `z = level*3.0`; stair holes are Boolean-cut through the slab above
  (cutter 2.9 × 3.8 m, `z = level*3 - 0.1`)
* roof at `z = floors*3.0`; `roof_flat` per cell, `roof_slanted` scaled by `(nx, ny, 1)`
* furniture anchors are a 3 × 5 lattice 2.5 m apart inside each cell, shuffled deterministically,
  and rejected if within 2.4 m of a doorway or 3.0 m of the stair

## Godot / Unity

Each building in `../buildings_modular/` is already a single joined mesh (including its furniture),
so one `ConcavePolygonShape3D` per building is enough for solid collision — windows, doorways and
the 6 m garage opening are real holes. If you build custom layouts in-engine, instance the modules
on the 15 m grid and keep the same origin convention.
