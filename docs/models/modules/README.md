## Grid convention used by the assembler
* module footprint **10 × 10 m**, storey height **3.0 m**, slab **0.2 m**
* footprint of an `nx × ny` building = `nx*10 × ny*10` metres
* side walls sit at `y = ∓D/2 + 0.1` (north/south) and `x = ∓W/2 + 0.1` (east/west)
* floor slabs at `z = level*3.0` (ground) or `level*3.0 - 0.2` (upper levels)
* roof at `z = floors*3.0`

## Godot / Unity
Each building in `../buildings/modular/` is already a single joined mesh, so one
`ConcavePolygonShape3D` per building is enough for solid collision (windows and
doorways are real holes). If you build custom layouts in-engine, instance the
modules on the 10 m grid and keep the same origin convention.
