## Notes
* `jharokha` is not a separate file — in the assembled Mahal (`rajasthani_mahal.glb`) jharokhas are protruding 2 m balconies with teal half-domes + pillars. Re-build them modularly by combining `wall_module` + `pillar_module` + scaled `dome_module` (see `examples/godot/modular_mahal_builder.gd`).
