Indus Asset Viewer — Phase 3: Mahal Palaces (50×50, Vibrant 40×30, Master Darbar & Modular Blocks)

Low-poly Battle Royale map environment built with Blender bpy for 4GB RAM devices — featuring the Mahal Palace (50m×50m × 15m, walls 15m thick) Hot Drop Fortress, Vibrant Stylized Palace (40m×30m base, 30m×20m×15m walls), Rajasthani Mahal Master — Exterior + Royal Darbar Interior (40m×30m base, 30m×20m×12m walls, sawtooth parapet, central teal dome r6 + 4 yellow r3, chhatris, checkered floor, 8 pillars, throne, jali, chandelier) and Modular Palace Blocks (wall 10×0.5×4 + gold border, arch 10×0.5×6 with r2 cutter + torus frame, dome r5 + spire, pillar r0.5 h6 with 3 bands) — hollow Boolean bases, trig arches via math.sin/cos, sliced domes with Kalash/cylinder+cone spires, plus Terrain (1000m ground, mountains, plateaus, valleys), Water & Bridges (ocean, river, beach, dam, bridges), Nature (trees, rocks, bushes), and Phase 1 Buildings. All props use 1K/2K PBR textures & solid Principled BSDF with bottom-center (0,0,0) origins.

Generated by tools/generate_mahal.py (50×50×15m) + tools/generate_mahal_vibrant.py (40×30 base, 30×20×15 walls, r8/r4) + tools/generate_mahal_master.py (40×30 base, 30×20×12 walls, procedural brick/checker, sawtooth parapet, multi-layer arches, jharokhas, central r6 + corner r3, chhatris, interior Darbar) + tools/generate_modular.py (wall 10×0.5×4 + arch 10×0.5×6 r2 + dome r5 + pillar r0.5 h6), tools/generate_terrain.py, tools/generate_water.py, tools/generate_bridges.py, tools/generate_nature.py & tools/generate_phase1.py (Blender bpy) → deployed automatically by GitHub Actions to GitHub Pages.
